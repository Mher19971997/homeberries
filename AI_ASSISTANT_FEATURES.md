# AI Помощник - Функции и Возможности

## 🤖 3D Робот-Ассистент

### Визуальные возможности:
- **Анимированный 3D робот** с реалистичной графикой
- **Анимация при разговоре**: робот двигает руками, открывает рот, мигает глазами
- **Автоматическое вращение** когда не говорит
- **Светящиеся элементы**: глаза и экран меняют цвет при активности

### Голосовые возможности:
- **Синтез речи (Text-to-Speech)**: робот говорит ответы голосом
- **Кнопка включения/выключения звука**: можно отключить голос
- **Естественная речь**: на русском языке с правильной интонацией

## 💬 Улучшенный UI

### Дизайн:
- **Современный градиентный дизайн** с плавными переходами
- **Анимация появления сообщений** для лучшего UX
- **Красивая прокрутка** с кастомным скроллбаром
- **Адаптивный дизайн** для мобильных устройств

### Функции:
- **Голосовой ввод**: говорите с роботом голосом
- **Текстовый ввод**: пишите сообщения
- **Рекомендуемые товары**: автоматический показ релевантных товаров

## 🎥 Интеграция с YouTube

### Возможности:
- **Автоматический поиск видео** о товарах
- **Встраивание видео** прямо в чат
- **Показ обзоров** когда пользователь спрашивает "как работает" или "покажи видео"

### Как это работает:
1. Пользователь спрашивает о товаре
2. AI находит товар в каталоге
3. Система ищет YouTube видео об этом товаре
4. Видео автоматически встраивается в ответ

## 🎯 Использование

### Примеры запросов:
- "Покажи мне iPhone 15"
- "Как работает MacBook Pro?"
- "Покажи видео обзор ноутбука"
- "Найди мне смартфон"

### Что происходит:
1. Робот получает запрос
2. Ищет товары в каталоге
3. Отвечает голосом (если включен звук)
4. Показывает рекомендуемые товары
5. Встраивает YouTube видео (если уместно)

## ⚙️ Настройка

### Включение/выключение голоса:
- Нажмите кнопку с иконкой динамика рядом с роботом
- Голос можно отключить в любой момент

### YouTube API (для продакшена):
1. Получите API ключ от Google Cloud Console
2. Добавьте в `.env`:
   ```
   YOUTUBE_API_KEY=ваш_ключ
   ```
3. Раскомментируйте код в `ai.service.ts` для поиска видео

## 🎨 Кастомизация

### Цвета робота:
- Основной цвет: `#667eea` (фиолетовый)
- Вторичный цвет: `#764ba2` (темно-фиолетовый)
- Акцент: `#00aaff` (голубой)

### Анимации:
- Скорость анимации: настраивается в `useFrame`
- Частота мигания рта: 200ms при разговоре
- Скорость вращения: 0.5 оборота в секунду
