# Настройка Stripe для тестовых платежей

## Шаги настройки

### 1. Получение тестовых ключей Stripe

1. Зарегистрируйтесь на [Stripe Dashboard](https://dashboard.stripe.com/register)
2. Перейдите в раздел **Developers** → **API keys**
3. Скопируйте **Publishable key** (начинается с `pk_test_`) и **Secret key** (начинается с `sk_test_`)

### 2. Настройка Backend

Добавьте в файл `homeberries_backend/config/local.env`:

```env
STRIPE_SECRET_KEY=sk_test_ваш_секретный_ключ
```

Или добавьте в `homeberries_backend/config/conf.json5`:

```json5
{
  stripe: {
    secretKey: 'sk_test_ваш_секретный_ключ'
  }
}
```

### 3. Настройка Frontend

Создайте файл `.env.local` в корне проекта `homeberries/`:

```env
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_ваш_публичный_ключ
```

### 4. Тестовые карты

Для тестирования используйте следующие тестовые карты:

**Успешный платеж:**
- Номер: `4242 4242 4242 4242`
- Дата: любая будущая дата (например, `12/34`)
- CVC: любые 3 цифры (например, `123`)
- ZIP: любые 5 цифр

**Отклоненный платеж:**
- Номер: `4000 0000 0000 0002`

**Требует 3D Secure:**
- Номер: `4000 0025 0000 3155`

Полный список тестовых карт: https://stripe.com/docs/testing

### 5. Запуск

1. Убедитесь, что backend запущен
2. Убедитесь, что frontend запущен
3. Перейдите на страницу корзины
4. Создайте заказ
5. Выберите способ оплаты
6. Используйте тестовую карту для оплаты

## API Endpoints

- `POST /api/v1/payment/create-intent` - создание payment intent
- `POST /api/v1/payment/confirm` - подтверждение платежа
- `GET /api/v1/payment/intent/:paymentIntentId` - получение информации о платеже

## Примечания

- Все платежи в тестовом режиме не списывают реальные деньги
- После успешной оплаты статус заказа автоматически обновляется на `paid`
- При ошибке платежа заказ остается со статусом `pending`
